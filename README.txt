GALAXY ON FIRE 2 (Gof2 by Inter) — браузерная версия
====================================================
Это J2ME-эмулятор freej2me-web (CheerpJ + WebGL 2) с вашим MIDlet'ом в jar/game.jar.

ЛОКАЛЬНЫЙ ЗАПУСК
  node server.js          (откроется http://localhost:8080/)
  или: npx serve -u .

ХОСТИНГ
  Залейте папку на любой хостинг, который поддерживает заголовок Range
  (GitHub Pages, Netlify, Cloudflare Pages, nginx). Нужен HTTPS (или localhost).
  Для работы нужен интернет: CheerpJ подгружается с cjrtnc.leaningtech.com.

УПРАВЛЕНИЕ
  Esc — меню настроек эмулятора (размер экрана, тип телефона, флаги совместимости, звук)
  Стрелки, Enter — D-pad и OK; 0-9, E (*), R (#); F1/Q и F2/W — софт-клавиши
  На телефонах/планшетах включается экранная клавиатура автоматически
  (принудительно: ?mobile=1).

ЕСЛИ ИГРА НЕ ЗАПУСКАЕТСЯ / ТОРМОЗИТ
  Esc -> поменять размер экрана, флаги совместимости, отключить звук -> перезапуск.
  Консоль браузера (F12) покажет ошибки.
